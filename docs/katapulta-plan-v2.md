**Версия:** v2 — этап 0 закрыт 16.10.2026, можно стартовать этапы 1–5
**Команда:** Андрей — конструктор · Глеб — физик · Тихон — код, испытания, сборка записки
**Контрольные параметры (подтверждены преподавателем):** x₁ = 1.2 м, x₂ = 1.5 м, отклонение от центральной оси ≤ 30°
**Модель:** рама и рычаг — печать PLA, оси — болты M6×80, энергия от резинок на хвосте рычага, спуск чекой, упор с демпфером из шланга.

## 0. Что определяет весь план

1.2–1.5 м — это очень слабый бросок. Нужная скорость снаряда у чашки: **3.14–3.67 м/с** на всём диапазоне углов.

| | |
|---|---|
| Окно дальности | ±11% |
| Окно скорости | ±6% |
| Окно энергии | ±13% |
| Цена 1% скорости | **23 мм дальности** |

Задача не «кинуть», а кинуть повторяемо **и** совпасть с расчётом. Трение в оси, гистерезис резинки и разброс взведения дадут больше расхождения, чем любая ошибка в формулах. Поэтому требование Р.7 (≤20%, желательно ≤5%) — это то, под что проектируется конструкция и ставится эксперимент Р.3, а не раздел, который пишется в конце.

## 2. Исходные числа — Глеб считает до появления железа

Из модели: ось рычага на 106 мм, L до центра чашки 130 мм, рычаг сплошным PLA 50.6 г, I относительно оси 2.77×10⁻⁴ кг·м², h₀ при β = 45° — 209 мм, ход резинки (хвост 35, ось A, β 45) — 36.1 мм.

| Величина | Значение | Почему важно |
|---|---|---|
| Целевая v | ≈ 3.39 м/с (β = 45°, дальность 1.35 м) | на 0.5–1% выше минимума (он при β = 40°), зато h₀ и ход резинки посчитаны именно для 45°. dx/dβ ≈ −6 мм на 1° — ошибка угла упора влияет слабо (для сравнения: 1% скорости = 23 мм) |
| Эквивалентная масса рычага у чашки | I/L² = 4–8 г (заполнение 25–50%) | при снаряде 25 г на рычаг уходит 14–24% энергии, а не половина |
| Масса снаряда | **25 г** (±1 г), Ø40, мягкий; в расчёт идёт фактическая масса | при 5 г сопротивление воздуха съедает ~7% дальности, при 20 г — ~2%, при 25 г не больше. 1 г массы ≈ 35–40 мм дальности |
| Запас в резинках | 0.17–0.27 Дж + потери | суммарная k ≈ 200–300 Н/м, сила взведения 10–14 Н. Полезная энергия (снаряд + рычаг) при m = 25 г, β = 45°, 1.35 м — 0.17–0.19 Дж, остальное — потери |

### Требуемая скорость по углам

|---|---|---|---|

*Проверка: строки 40–55° воспроизводятся пересчётом при h₀ = 209 мм, g = 9.81 с точностью до 0.01 м/с; строка 45° совпадает точно. На краях (30, 35, 60°) пересчёт даёт на 0.02–0.03 м/с другие значения — для выбранного β это не важно.*

### Две вещи, на которых обычно сыплются

- **Работа резинки = ½k(x_взв² − x_ост²), а не ½kΔ².** Петля остаётся натянутой в момент вылета — это прямо оговорено в панели модели. Расчёт по ходу Δ даёт завышение.
- **Теорема Карно из методички — ровно про эту конструкцию.** Рычаг бьёт в упор со шлангом в тот самый момент, когда снаряд отрывается. Кинетическая энергия рычага в этот момент и есть «остаточная энергия, уходящая в удар». Внести её в баланс Р.4 явно — бесплатные баллы.

## 3. Где теряются 20%

**Р.3, гистерезис латекса — Глеб.**
Снимать и нагрузку, и разгрузку. Энергию отдаёт разгрузочная ветвь, а k по нагрузке систематически завышен на 10–15% → это 20% по дальности, то есть ровно вылет за критерий. В записку обе ветви, в расчёт — разгрузочную, с обоснованием. Это же объяснит остаточные 5% преподавателю.

**Р.6, площади против масс — Глеб.**
Формулы методички через Aᵢ верны только для однородной плоской пластины. Здесь три болта M6×80 — это ~60 г стали против печатной рамы примерно в 100 г при заполнении. Считать через массы:

```
x_ц.т. = Σ mᵢxᵢ / Σ mᵢ        y_ц.т. = Σ mᵢyᵢ / Σ mᵢ
```

Массы — с весов, подетально, **до сборки** (Андрей взвешивает и передаёт). Подмену обосновать одной строкой: Aᵢ — частный случай при постоянных ρ и толщине.

**Р.7, выбор начала координат — Тихон.**
Относительная погрешность координаты зависит от того, откуда она отсчитывается. Начало и оси зафиксированы в этапе 0 (угол основания по рис. 2в); y_ц.т. выйдет 60–80 мм, и 5 мм ошибки измерения — это уже 7%. Чтобы уложиться в 5%, абсолютная ошибка должна быть не больше 3 мм. Подвешивать на тонкой нити, линию бить отвесом, не на глаз.

**Р.7, число пусков — Тихон.**
Требуется минимум 3 — делать 10, в записку среднее по 10 плюс разброс. Среднее по трём пускам при этом разбросе легко промахнётся мимо окна.
