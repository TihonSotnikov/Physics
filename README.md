# Катапульта — калькулятор

Курсовой проект «Катапульта» (механика, НГУ). Весь расчёт и CLI — в
`catapult.py`.

## Запуск

```
uv sync
uv run python catapult.py [флаги]
uv run pytest
uv run ruff check . && uv run ruff format --check .
```

Один запуск печатает отчёт (7 разделов) и показывает график.

## Флаги

| Флаг | По умолчанию | Смысл |
|---|---|---|
| `--k` | 250 | суммарная жёсткость резинок, Н/м |
| `--l-free` | 50 | свободная длина петли, мм (ВРЕМЕННО, измерить) |
| `--tail` | 35 | отверстие на хвосте рычага: 35, 45, 55 |
| `--rod` | A | нижняя ось резинок: A или B |
| `--beta` | 45 | положение упора, град |
| `--m-ball` | 25 | масса снаряда, г |
| `--m-arm` | 50.6 | масса рычага, г (сплошной PLA, заменить взвешенной) |
| `--inertia` | 2.767e-4 | момент инерции рычага, кг·м² (заменить измеренным) |
| `--period` | — | период колебаний рычага на оси, с; переопределяет `--inertia` |
| `--target` | 1.35 | нужная дальность, м (обратный режим) |
| `--k-loop` | — | жёсткость одной петли, Н/м; даёт число петель |
| `--save` | — | сохранить график в PNG |
| `--no-plot` | — | не показывать график |

Мм и граммы переводятся в СИ один раз в `parse_args`.
